========================================
   CertMaster - 部署包清单
========================================

📦 需要复制的文件和文件夹：

必需文件（不能删除）：
├── backend/                    # 后端代码（完整）
├── frontend/                   # 前端代码（完整）
├── data/                      # 数据目录
│   ├── certificates/          # 证书图片
│   ├── configs/              # 模板配置
│   ├── templates/            # 用户模板
│   ├── certificates.json     # 证书数据
│   └── templates.json        # 模板数据
├── 启动.bat                   # 启动脚本 ⭐⭐⭐
├── 部署指南.md               # 详细部署说明
├── 快速部署指南.txt          # 快速参考
└── README.md                 # 项目说明

可选文件（可删除）：
├── node_modules/             # 可删除，会自动安装
├── scripts/                  # 可删除（辅助脚本）
├── .git/                     # 可删除（版本控制）
└── *.log                     # 可删除（日志文件）

========================================
📋 部署流程（给接收者）
========================================

1. 安装环境
   □ Python 3.8+  (记得勾选 Add to PATH)
   □ Node.js 16+

2. 解压/复制项目文件夹到电脑
   例如：D:\CertMaster\

3. 双击运行 "启动.bat"

4. 浏览器访问 http://localhost:5173

完成！

========================================
💾 最小部署包（约 50MB）
========================================

如需创建最小部署包，只需包含：

CertMaster/
├── backend/          # 后端（约 5MB）
├── frontend/         # 前端（约 30MB，含 node_modules）
│   ├── public/
│   ├── src/
│   ├── index.html
│   ├── package.json
│   └── vite.config.ts
├── data/            # 数据（约 5MB）
├── 启动.bat
└── 部署指南.md

⚠️ 注意：frontend/node_modules/ 会自动安装

========================================
🔄 数据迁移说明
========================================

如需迁移证书数据：
只需复制 data/ 文件夹即可！

data/
├── certificates.json      # 所有证书参数
├── certificates/         # 所有证书图片
└── configs/             # 模板配置
