            CertMaster 证书制作系统 - 启动说明
═══════════════════════════════════════════════════════════

📌 快速启动（选择一种方式）：

┌─────────────────────────────────────────────────────────┐
│  方式 1：双击启动（最简单）⭐                              │
├─────────────────────────────────────────────────────────┤
│  Windows 用户：                                           │
│    👉 双击 "启动.bat" 文件                                 │
│                                                          │
│  Linux/Mac 用户：                                         │
│    👉 在终端运行: ./start.sh                              │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  方式 2：PowerShell 启动（Windows 推荐）                   │
├─────────────────────────────────────────────────────────┤
│  1. 在项目目录右键，选择 "在终端中打开"                     │
│  2. 输入命令：.\start.ps1                                 │
│  3. 按回车                                               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  方式 3：Python 脚本启动（跨平台）                         │
├─────────────────────────────────────────────────────────┤
│  在项目目录打开终端，运行：                                 │
│    python scripts/start.py                               │
└─────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════

🌐 启动后访问地址：

    前端页面：http://localhost:5173
    后端 API：http://localhost:8000
    API 文档：http://localhost:8000/api/docs

═══════════════════════════════════════════════════════════

⚙️ 首次启动前的准备：

    1. 确保已安装 Python 3.8+
    2. 确保已安装 Node.js 14+
    3. 脚本会自动检查并安装依赖
