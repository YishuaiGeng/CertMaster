========================================
  CertMaster 证书制作系统 - 快速部署
========================================

📋 部署步骤（5分钟完成）

1️⃣ 环境准备
   - 安装 Python 3.8+  (https://www.python.org/downloads/)
   - 安装 Node.js 16+   (https://nodejs.org/)
   ⚠️ 安装 Python 时勾选 "Add Python to PATH"

2️⃣ 复制项目
   - 将整个 CertMaster 文件夹复制到目标电脑
   - 例如：D:\CertMaster\

3️⃣ 启动服务
   - 双击运行 "启动.bat"
   - 等待两个窗口打开（后端和前端）
   - 脚本会自动安装依赖

4️⃣ 访问系统
   - 打开浏览器
   - 访问：http://localhost:5173

========================================
📂 数据迁移（可选）
========================================

如需迁移旧数据到新电脑：

方法一：复制数据文件夹
  将旧电脑的 data/ 文件夹
  复制并覆盖到新电脑的项目目录

方法二：使用导入导出功能
  1. 旧电脑：打开系统 → 设置 → 导出配置
  2. 新电脑：打开系统 → 设置 → 导入配置

========================================
❓ 常见问题
========================================

问题1：提示"未找到 Python"
解决：重新安装 Python，勾选 "Add Python to PATH"

问题2：提示"未找到 Node.js"  
解决：确认 Node.js 已正确安装，重启命令提示符

问题3：端口被占用
解决：关闭占用 8000 或 5173 端口的程序

问题4：页面空白
解决：按 F12 查看控制台错误，刷新页面（Ctrl+F5）
